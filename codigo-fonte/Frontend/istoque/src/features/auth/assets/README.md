# Ativos de acesso

`mascote.png` e `textura.jpg` são as imagens originais do projeto, usadas sem alterações.

Login e cadastro são construídos com HTML semântico e CSS em `components/auth-screen.jsx`, `components/access-form.jsx`, `components/auth-controls.jsx` e `components/auth.css`. Nenhuma tela completa exportada do Figma é usada como imagem. Textos, títulos, campos e botões são elementos reais. A curva lateral é uma forma vetorial decorativa definida em código.

Referência: Figma ISTOQUE, login desktop `3:26`, cadastro `2:69`, versões móveis `3:29` e `2:44`. As anotações de dimensões foram removidas.
